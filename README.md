# CS624-PE01-Enzo-Nguyen

The input data for this "Hello World" mobile application consists of text information defined directly within the program: my name, my academic program, and the name of my university. Specifically, this information is: Enzo Nguyen, MSCS, and City University of Seattle.

The program utilizes React Native components to display this information. A View component contains three Text components. A StyleSheet is used to define the screen's appearance; it sets the background color to yellow, the text color to black, and centers the text on the screen. The justifyContent and alignItems properties ensure the text is centered both vertically and horizontally. When the application runs, React Native reads the source code and generates the user interface.

The output is a mobile application featuring a yellow background with three lines of black text centered on the screen. These lines display my name, academic program, and university name. This application illustrates the "input-process-output" model: the program takes predefined text as input, processes it using React Native components and styles, and displays the final result on the screen.
